# V5 decision register

Decisions taken while implementing the developer package v5 (Excel v5.0, Word v2.0, mockups v6). Each decision says whether the **client** confirmed it or **I inferred** it. An inferred decision is a proposal the client can overrule; the last column says how hard that is.

Order of authority used (stated by the product owner, 25-11-2026): the Excel for form fields, the Word for menus, portals, Actions, Rapid Verify, Reports, Management and permissions, the mockups for layout. Where two sources of the same rank disagree, the newer explicit correction wins, then the more specific statement, then the existing application convention.
