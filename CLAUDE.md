# UI rules

Read [the product design direction](docs/product/design-direction.md) and [the UI audit](docs/operations/ui-ai-slop-audit.md) before editing the web UI. Use the tokens in `apps/web/app/styles/tokens.css` for colour, type, radius, and shadow. Keep status colour for record state and orange for the current selection and one primary action per view.

Avoid decorative gradients, glass effects, tinted icon squares, uppercase eyebrows above headings, coloured modules, nested cards, fake empty-state content, invented figures, and ambient or looping motion. Preserve behaviour, permissions, data flow, accessible names, roles, and test selectors when making visual changes.
